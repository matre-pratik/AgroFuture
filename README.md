# AgroFuture

## Project Overview
AgroFuture is a responsive agricultural service website designed to provide information and connect users with farming resources.  
The project is built using HTML, CSS, and JavaScript with a focus on clean UI and responsive design.

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Responsive Design

## Key Features
- Fully responsive layout for desktop and mobile devices
- Navigation bar with smooth scrolling
- Informational sections such as services, about, and contact
- Clean and minimal user interface
- Easy to extend for future features

## Live Demo
https://matre-pratik.github.io/AgroFuture/

## How to Run Locally
1. Clone the repository
2. Open `index.html` in your browser.

## Concepts Demonstrated
- Semantic HTML structure
- Responsive layouts using CSS Flexbox/Grid
- Basic JavaScript DOM manipulation
- Cross-browser compatibility
